# Ja Music Android APKs

Two separately installable Android applications, built from the **unchanged** Ja Music HTML prototypes:

- **Ja Music** (`na.jamusic.listener`) — listener demo
- **Ja Music Studio** (`na.jamusic.studio`) — artist demo

Both are lightweight native Android WebView containers, not a Flutter rebuild. They include the full prototype HTML inside the APK and work offline using a secure local `https://appassets.androidplatform.net` origin, with JavaScript and browser local storage enabled. Audio and cover file pickers are supported in Studio. The official Ja Music logo is used as the launcher icon, and the HTML splash screen and user interface are unchanged.

## Download the APKs through GitHub

1. Open **Actions** in https://github.com/Jeckson77/ja-music/actions/workflows/build-android-apks.yml
2. Open a successful **Build Ja Music Android APKs** run.
3. Download `Ja-Music-Listener-APK` and `Ja-Music-Studio-APK` from the run's **Artifacts** section. Extract each ZIP to find its APK.
4. Copy each APK to your Android phone and tap it to install. Android may ask permission to install from that file source. Only install builds you trust.

The workflow also produces `Ja-Music-Android-Demo-Package`, containing both APKs. These are **debug-signed demonstration builds**, not production releases suitable for Play Store publishing. GitHub Actions artifacts have a 30-day retention setting and can be regenerated by running the workflow again.

## How to build locally

Prerequisites: JDK 17, Android SDK API 35, Gradle 8.9. From the `android/` directory run:

```bash
gradle :app:assembleListenerDebug :app:assembleStudioDebug
```

Output APKs:
- `android/app/build/outputs/apk/listener/debug/app-listener-debug.apk`
- `android/app/build/outputs/apk/studio/debug/app-studio-debug.apk`

## Prototype limitations

- The **installed apps do not have a shared cloud database**. Android sandboxes each APK's local browser storage separately, so an upload in the installed Studio app **will not automatically appear** in the separately installed Listener app.
- To show the connected publish-to-purchase flow on the same device/browser, use the existing [two-phone public demo](https://ja-music-namibia.onrender.com/ja_music_dual_demo.html).
- Auth, purchases, music playback demonstrations, payout requests and earnings remain simulated; no real financial transactions or licensed streaming occur.
- No changes are made to the existing listener.html, artist.html or website by this Android build.

A production cross-device system would require authenticated backend APIs, a persistent server database, licensed audio infrastructure, and real payment provider integrations.
