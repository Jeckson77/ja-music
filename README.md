# 🎵 Ja Music — Say Ja to Local Music

**A Namibian digital music marketplace prototype connecting independent artists and listeners.**

[Explore the website](https://ja-music-namibia.onrender.com/) · [Try the interactive prototype](https://ja-music-namibia.onrender.com/demo.html) · [Front-End Skills reference](https://github.com/Jeckson77/Front-End-skills)

## Two experiences, one ecosystem

- **Ja Music Listener:** Discover music, explore releases, and try simulated purchases and gifting.
- **Ja Music Studio:** Explore an artist workflow for draft releases, publishing, and simulated earnings.

> **Prototype disclaimer:** The demonstration uses example data and demo accounts. Payments, artist credits, and airtime billing are not real transactions. The static demo uses browser storage; the included Python server can provide a local SQLite-backed demonstration.

## Try it

1. Open the [interactive demo](https://ja-music-namibia.onrender.com/demo.html).
2. Use **Try the demo account** in the Listener and Studio experiences.
3. Publish an example release in Studio, find it in Listener, and test a simulated purchase.
4. For a wider view, select **Open full screen**.

## Frontend improvements

The site applies principles referenced by [Jeckson77/Front-End-skills](https://github.com/Jeckson77/Front-End-skills), with original skill guidance credited to [Emil Kowalski's skills collection](https://github.com/emilkowalski/skills):

- Responsive layout and mobile-friendly touch targets.
- Visible keyboard focus and skip navigation.
- Purposeful hover feedback and reduced-motion support.
- High-contrast mode refinements and accessible demo guidance.
- Consistent Listener and Studio visual language.

**Frontend files:** `index.html`, `demo.html`, `styles.css`, `frontend-website.css`, `frontend-skills-enhancements.css`, `website.js`, and `frontend-website.js`.

## Local development

Serve the repository using the included Python server for the SQLite-backed demo where supported, or use a local static server for the browser-storage prototype. Avoid entering real passwords or payment information in the demo.
